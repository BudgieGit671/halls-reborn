# HALLS

This is the official Godot port of the unpopular semi-horror scratch game HALLS. <br />

Project is in early development stages, not yet playable. <br />

Meanwhile, you can play the original game on [Scratch](https://scratch.mit.edu/projects/746013689/) or [Turbowarp](https://turbowarp.org/746013689) <br />
...or even hang around on our [Discord](https://discord.gg/va2Wdvd6A5) <br />
Thanks for your patience!
