# HALLS

This is the official Godot port of the unpopular semi-horror scratch game HALLS. 

Project is in early development stages, not yet playable.

Meanwhile, you can play the original game on [Scratch](https://scratch.mit.edu/projects/746013689/) or [Turbowarp](https://turbowarp.org/746013689)
...or even hang around on our [Discord](https://discord.gg/va2Wdvd6A5)
Thanks for your patience!
